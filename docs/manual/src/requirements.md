# Requirements and assumptions

## Requirements

- OxiGuitar 0.20 or later (plugin interface 1.8). See [the OxiGuitar manual](https://mateusrdp.github.io/oxiguitar/).
- The MIDI plugin, installed. OxiGuitar won't use this plugin without it. See [its manual](https://mateusrdp.github.io/oxiguitar-midi/).
- Windows, macOS or Linux.
- A computer with room to spare. If playback stutters, use the amp on fewer tracks or pick lighter models, labelled "lite", "feather" or "nano".

## Assumptions

- You bring your own amp models. Check each one's licence before you share what you play through it.
- The track feeds the amp a clean sound. The plugin can't see the Sound section, so it only reminds you.
- Settings are saved per track beside the score, in its `.oxg` file. The score itself doesn't change. A missing model file plays without it, and the footer says so.
